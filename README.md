# 📚 LJCourses

A modern online learning platform built with Python & Flask.

## 🚀 Features
- User authentication & registration
- Browse and enroll in courses
- Track learning progress
- Admin dashboard for course management

## 🛠️ Tech Stack
- **Backend:** Python, Flask
- **Database:** PostgreSQL
- **ORM:** SQLAlchemy

## ⚙️ Installation

1. Clone the repository
   git clone https://github.com/Pratik9516/LJCourses.git

2. Create virtual environment
   python -m venv venv
   venv\Scripts\activate

3. Install dependencies
   pip install -r requirements.txt

4. Setup PostgreSQL database and update config

5. Run the project
   python run.py

6. Open browser
   http://localhost:5000
